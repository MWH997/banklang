BankLang playground

A deterministic compiler from BankTS, a restricted TypeScript-like language, to readable IBM COBOL. The real compiler runs here in your browser — no server, no network call. Edit the program, watch the COBOL change, then Run it.

Compiling…

Edit this. It recompiles as you type. Click any line to trace it into the COBOL beside it, or open Run to execute the COBOL and see what it posts.

Click a line in either pane to trace it through the source map.

Generated COBOL is validated locally with GnuCOBOL in CI. No IBM Enterprise COBOL validation is claimed.
