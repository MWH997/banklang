# Open Testing Ecosystem

## Purpose

BankLang should have an open-source testing lane in addition to future IBM Z validation.

## COBOL Check

COBOL Check provides fine-grained unit testing/checking for COBOL. The Open Mainframe Project GitHub repo currently marks it as Emeritus, so it should be evaluated carefully before depending on it.

## Galasa

Galasa is an open-source deep integration test framework. IBM Distribution for Galasa documentation describes deep integration with z/OS middleware and open-source test tools, including interrogating CICS, IMS, and other applications.

## BankLang testing roadmap

- local unit/golden/property tests
- GnuCOBOL smoke tests
- COBOL Check feasibility review
- Galasa integration-test roadmap
- ZUnit future lane
- IBM validation lab
