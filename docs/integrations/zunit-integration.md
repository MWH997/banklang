# ZUnit Integration

## Purpose

BankLang needs a credible IBM Z unit-testing roadmap.

## Source of truth

Use IBM ZUnit documentation.

## Research finding

ZUnit adapts xUnit concepts for repeatable, self-checking tests for Enterprise COBOL and PL/I.

## BankLang roadmap

Potential generated artifacts:

- COBOL unit-test harnesses
- BankTS-to-test mapping
- fixture declarations
- expected output records
- source map from generated test to BankTS source

## v0.1 scope

Document only. Use local tests and golden tests first.
