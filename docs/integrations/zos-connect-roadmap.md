# z/OS Connect Roadmap

## Purpose

z/OS Connect is not v0.1 scope, but it matters for future API modernization.

## Source of truth

Use IBM z/OS Connect documentation.

## Research finding

z/OS Connect Designer supports OpenAPI 3.0 APIs and contract-first API creation. IBM docs describe COBOL programs calling APIs using generated communication stubs and request/response data structures. z/OS Connect docs also describe CICS COBOL API requester scenarios and IMS COBOL mapping enhancements.

## BankLang roadmap ideas

- copybook-to-OpenAPI mapping research
- OpenAPI-to-copybook generated structures
- API requester artifact awareness
- CICS/IMS API exposure documentation
- generated API evidence reports

## v0.1 scope

No implementation. Keep as roadmap.
